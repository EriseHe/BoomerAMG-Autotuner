# 从可靠性触发到成本驱动的 RL 启动

研究草稿，2026-09-13。本文提出问题定义、可证明的判据及其限制，不表示现有 runner 已实现这些机制。本轮没有运行新的 PDE 实验，没有修改算法、论文或已有实验结果。

本文接续 [4D dynamic 机制诊断](context_activation_mechanism_diagnosis_20260913.md)。旧的 reliability mixture test 的概率论证明仍成立；需要改变的是它所支持的论文主张。它控制持续不可靠条件下的误触发，不能决定哪个启动时刻会使联合学习的累计成本最低。

## 1. 先确定真正的决策对象

设第 t 个问题为 \(\xi_t=(A_t,b_t,u_t^{(0)},\varepsilon_t)\)，其 setup context 为 \(x_t\)。setup action 为 \(a_t\)，生成 hierarchy \(\mathcal H_t\)；第 k 个 cycle 的 solve action 为 \(w_{t,k}\)，由策略 \(\pi\) 根据 solver state 决定。本文将 LSTDQ 的有限维 state features 记为 \(\varphi(s)\in\mathbb R^{d_s}\)（旧笔记的 \(x(s)\)），与 setup context 区分。实际 solver state 与这些特征不混为一谈，理论并不先假设该特征是充分的 Markov state。

令 \(Z_t\) 包含完整的跨问题学习状态：bandit 和 controller 的参数、统计矩阵、探索计数、candidate anchors/cursor、RNG 状态、成本记忆等。启动 RL 会改变 \(Z_t\) 的转移规律，进而改变之后的 setup 和 solve。相同问题 seed 不能消除这些路径差异。

成本口径固定为达到指定容差所需的 setup、solve、恢复及被计入目标的全部学习/决策开销。额外训练、重复验证和切换开销也必须入账。若矩阵生成是所有方法共享且相同的成本，可以统一排除；专属于新方法的预计算不能因此自动排除。主实验现有的 end-to-end 字段不等于整个 Python 进程持续时间。

以下成本比较要求两种部署协议按同一容差返回有效解，primary 超限后按既定恢复协议完成求解。若还允许最终失败，则需另行规定并分析最终失败约束；更早报错退出不能计作更快完成同一个求解任务。

需要区分三个时刻/判断：

| 判断 | 要回答的问题 | 所需信息 |
|---|---|---|
| 开始探索训练 | 现在获取 RL 数据的预期价值是否值得其成本？ | 探索的成本、覆盖及潜在信息价值 |
| 正式部署候选策略 | 已有候选在剩余问题上是否有可信的净成本优势？ | 同一 comparator 下的候选性能及可外推范围 |
| 整个方案回本 | 后续节省能否覆盖此前训练、验证和切换的额外支出？ | 完整的累计成本账本 |

当前实现把前两项合并成一次不可逆的启动，并在启动后继续改变两个 learner。对于这种实现，仅检验启动前的默认 solve 失败率，缺少判断后两项所需的信息。

### 命题 1：默认轨迹无法识别未尝试策略的成本优势

考虑两个环境，在默认策略下每题都成功且成本恒为 1。在环境 \(\mathsf E_+\) 中，某候选 solve policy 每题成本为 1/2；在环境 \(\mathsf E_-\) 中，其成本为 2；两者也都成功。任何只使用默认轨迹、且尚未执行能区分两个环境的动作的启动规则，在两个环境中的启动概率相同，记为 q。

于是，它在 \(\mathsf E_-\) 中错误启动的概率为 q，而在 \(\mathsf E_+\) 中错过有益启动的概率为 1−q；两者之和为 1，至少一个不小于 1/2。

**证明。** 默认策略产生的全部可见数据分布相同，故任何依赖这些数据及独立内部随机数的决策，其分布也相同。余下是代数。∎

该反例甚至允许观察完整的默认成本和残差轨迹，而非只有 failure indicator。若要排除它，必须加入候选动作数据、可识别的动力学模型，或足以联系不同动作成本的结构假设。不能只更换一个 failure threshold。

## 2. 为什么当前有收益仍不能保证长期联合收益

从完全相同的历史处分叉。协议 0 继续 bandit + 默认 solve \(\pi_0\)；协议 1 开始指定的联合学习过程。让两者面对相同的外生问题流。记未来第 s 个问题所选 setup 为 \(a_s^0,a_s^1\)，联合协议的 solve policy 为 \(\pi_s^1\)。

在共同的条件成本模型下，令 \(c(\xi,a,\pi)\) 为不含 learner 开销的条件期望 setup+solve+恢复成本。将 learner、验证和切换的条件期望额外开销差记为 H。则剩余 N 题的条件期望净节省有精确分解

\[
\begin{aligned}
G_N
={}&\underbrace{\mathbb E\sum_{s=1}^{N}
 [c(\xi_s,a_s^0,\pi_0)-c(\xi_s,a_s^1,\pi_0)]}
 _{\text{setup 学习路径项}}\\
&+\underbrace{\mathbb E\sum_{s=1}^{N}
 [c(\xi_s,a_s^1,\pi_0)-c(\xi_s,a_s^1,\pi_s^1)]}
 _{\text{给定联合路径 setup 后的 solve 改善项}}-H .
\tag{1}
\end{aligned}
\]

所有期望均条件于共同分叉历史；式 (1) 只是逐项加减中间成本，无需线性 realizability。但这些中间成本是 counterfactual，并非现有单条日志已观测的数据。

即使第二项始终为正，第一项仍可能足够负，使总收益变差。setup 在默认 solve 下的优劣也不必等同于在某个 learned solve policy 下的优劣。若 comparator 是延迟到第 1001 题后再启用 RL 的完整协议，需在同一分叉历史下比较两套完整更新协议，而不能只替换式中的启动题号、保持未来路径不变。

已有交叉诊断提供了具体例子：在最终 checkpoint 的 25 个所选问题上，两种 setup 来源与两种 controller 的平均 cycle 数矩阵为

\[
\begin{pmatrix}
11.16&13.76\\
15.60&12.44
\end{pmatrix}.
\]

行分别是固定启动和 dynamic 的 setup 来源，列是相应 controller 来源。两个对角组合均优于只替换一个组成部分后的组合，但第二个对角组合仍慢于第一个。这个有限矩阵支持联合适配的解释，不证明全参数空间的局部极小点，也不识别启动时刻的因果效应。[数据与限制](context_activation_mechanism_diagnosis_20260913.md)

因此，“在当前 hierarchy 上 RL 比 weight=1 快”是有意义的 solve 结论，但不足以证明“立即开始持续联合学习优于等待”。

## 3. 真正的最优启动问题：完整协议的 optimal stopping

设 h 为当前全部可见历史，剩余 N 个问题。预先指定启动后所执行的完整训练/部署协议 \(\mathsf A\)，包含 setup 如何更新、RL 如何探索以及失败如何恢复。

定义

\[
F_N(h)=\mathbb E[\text{现在启动 }\mathsf A\text{ 的剩余总成本}\mid h],
\]

\[
V_N(h)=\min\left\{
 F_N(h),\quad
 \mathbb E[C^{\rm off}_{\rm next}+V_{N-1}(h')\mid h]
\right\},\qquad V_0(h)=0.
\tag{2}
\]

h′ 是再执行一个未启动问题后的历史。式 (2) 的最优停止条件是“立即启动的 continuation cost 不大于等待后继续最优决策的 cost”。若再允许单独的 probe 动作，Bellman 最小值中需要加入该动作的成本和信息更新分支。

式 (2) 精确定义了原始研究问题，但没有给出免费可计算的答案：当前日志没有识别 \(F_N\) 或所有 counterfactual 转移。仅把 failure rate 换成某个 cost rate，也不会自动得到这些价值函数。

如果真实模型已知，且策略类包括固定第 1001 题启动，那么最优动态规则的**期望**成本不会高于这个固定规则。这是优化集合包含关系的结论。它不意味着某个实际设计的 dynamic rule 已达到最优，更不意味着每个 seed、每次计时实现上都优于固定启动。

若坚持直接验证原始启动决策，观测单位应是从同一 h 出发、覆盖剩余时域的**完整协议成本差**，而不是某一题上两个 solve policy 的成本差。独立的共同状态分叉 rollout 可用于估计它，代价也必须入账。只做短 rollout 则仍需要控制未评估尾段的价值误差。这个办法适合识别启动效应的研究验证，目前不建议把昂贵的完整未来 rollout 当作在线 gate。

## 4. 可操作的较窄目标：验证并部署一个联合候选

为了得到当前研究能承受的理论，建议先处理以下明确目标：在一个已知 incumbent 与一个已训练候选之间，决定何时已有足够证据部署候选，并为剩余预算给出成本保证。

第 m 次提案包含

\[
\mathsf P_m^0=(\eta_m^0,\pi_m^0),\qquad
\mathsf P_m^1=(\eta_m^1,\pi_m^1),
\tag{3}
\]

其中 \(\eta\) 是从问题 context 到 setup action 的选择规则，\(\pi\) 是一个求解内部的 sequential relaxation policy。首次提案的 incumbent 可以是已学到的 setup selector 加默认 solve；后续 incumbent 可以是已经验证的联合策略。

必须明确验证哪种 comparator：

| 设计 | 能支持的结论 |
|---|---|
| \(\eta_m^0=\eta_m^1\)，仅替换 solve | 当前 setup 分布上 solve policy 的增量效果 |
| 两个完整联合候选同时比较 | 这两个 setup–solve 组合之间的成本差 |
| 从共同学习状态复制并运行两套未来更新协议 | 两套联合学习协议的有限时域效果 |

对于 4D 所暴露的问题，第二种是直接可管理的部署对象；第三种才直接对应“现在开始训练还是等到 1001”，但其观测代价明显更高。

每次提案在其验证数据到达前确定。验证期间冻结被评估版本的**完整决策规则**，而不只是 theta：setup anchors、candidate 生成规则、exploration schedule、confidence bonus 和跨问题计数的变化也会改变策略。允许一个 solve 内根据残差历史改变 relaxation；冻结不等于 fixed weight。

若希望继续改变验证对象，必须明确它是一个变化的协议，并使用第 6 节的外推假设；不能仍称其为同一固定策略的均值估计。另一种办法是保存 incumbent，在独立训练副本上更新，随后把完整新版本作为下一次提案验证。

在新的、未用于选择该版本的问题上，使用同一矩阵、RHS、初值和容差评估两者，定义配对成本差

\[
D_{m,i}=C_{m,i}^0-C_{m,i}^1.
\tag{4}
\]

正值表示候选更快。两次评估的额外支出另入验证成本账本，不能把“一题跑两遍”的时间当成免费。不能只保留成功样本；失败及恢复按既定成本定义进入 C。

配对能减少问题难度带来的方差，但不自动消除缓存、执行顺序和机器负载的影响。需要预先规定测量协议，并说明该测量分布为何能代表部署成本。随机化运行顺序是处理顺序偏差的方法之一，不是任意时变系统下的普遍保证。

## 5. 一个没有固定窗口的成本 confidence sequence

下面给出便于逐步检查证明的版本；它并非新的通用统计不等式。Confidence sequence 的核心是对所有查看时刻同时有效，已有更紧的方差自适应构造可在明确噪声假设后使用。[Howard 等，2021](https://arxiv.org/abs/1810.08240)

令 \(\mathcal G_{m,i-1}\) 为第 i 个配对观测前的可见历史，

\[
g_{m,i}=\mathbb E[D_{m,i}\mid\mathcal G_{m,i-1}],
\qquad
\bar g_{m,n}=\frac1n\sum_{i=1}^n g_{m,i}.
\]

假设存在提案开始前确定的、已知有效的 \(\sigma_m>0\)，使所有实数 \(\lambda\) 满足

\[
\mathbb E[\exp\{\lambda(D_{m,i}-g_{m,i})\}
 \mid\mathcal G_{m,i-1}]
\le \exp(\lambda^2\sigma_m^2/2).
\tag{5}
\]

这允许依赖观测和变化的条件均值，并不要求独立同分布。\(\sigma_m\) 不能未经证明地用同一批样本标准差替代。

一个充分条件是两种完整成本均有事先已知的硬界 \(0\le C\le C_{\max}\)；此时差值区间长度为 \(2C_{\max}\)，条件 Hoeffding 引理允许取 \(\sigma_m=C_{\max}\)。现有 50-cycle cap **不是 wall-clock 硬界**。若用截断成本建立硬界，保证针对截断后的目标；不能再声称它自动保证原始未截断平均时间。当前数据尚未验证 (5)，因此下面是带明确假设的理论，而非已经校准好的实际 95% 保证。

给所有提案分配 \(\delta_m=\delta/[m(m+1)]\)，并定义

\[
r_{m,n}=\sigma_m
\sqrt{\frac{2}{n}
 \log\frac{2m(m+1)n(n+1)}{\delta}},
\]

\[
L_{m,n}=\bar D_{m,n}-r_{m,n},\qquad
U_{m,n}=\bar D_{m,n}+r_{m,n}.
\tag{6}
\]

### 引理 2：所有提案、所有样本数的同时覆盖

在 (5) 下，提案可以依赖之前的全部数据，只要新提案的验证观测满足上述条件，就有

\[
\Pr\{\forall m,n\ge1:
 L_{m,n}\le\bar g_{m,n}\le U_{m,n}\}\ge1-\delta.
\tag{7}
\]

**证明。** 对固定 m,n，迭代条件矩母函数并用 Chernoff 界，得到
\(\Pr\{|\bar D_{m,n}-\bar g_{m,n}|>r\}\le
2\exp[-nr^2/(2\sigma_m^2)]\)，该结论条件于提案开始历史也成立。代入 (6)，失败概率不超过
\(\delta/[m(m+1)n(n+1)]\)。对所有 m,n 作 union bound，并用
\(\sum_{j\ge1}1/[j(j+1)]=1\)。∎

每来一个验证样本就可以重新判断，没有“每 100 个样本算一块”的结构。提案编号的误差分配允许不断生成新模型，但并不允许用选择模型时反复查看过的旧验证集，再把新模型当作事先固定的对象重测。简单有效的实现是每个新版本只使用其确定之后的新验证观测。

尤其要注意，(7) 一般覆盖的是**过去条件均值的平均值** \(\bar g_{m,n}\)。若候选或问题分布变化，它本身不覆盖下一题，更不覆盖未来 4000 题。

## 6. 成本部署判据及完整保证

在观察到提案 m 的 n 个配对样本后，决定从下一题起部署候选 N 题。N 在决策时确定，不能超过剩余问题预算。令

- \(K_{m,n}\ge0\)：部署后的额外切换/实现成本的有效上界；已经包含在式 (4) 的每题成本中的项不重复计算。
- \(B_{m,n}(N)\ge0\)：从验证条件外推到该部署协议的累计优势损失上界。

形式上，要求未来的潜在成本差 \(D_r^{\rm dep}\) 满足

\[
\mathbb E\left[\sum_{r=1}^{N}D_r^{\rm dep}
 \middle|\mathcal G_{m,n}\right]
\ge N\bar g_{m,n}-B_{m,n}(N).
\tag{8}
\]

式 (8) 是实质性假设，不是定义一个未知 B 后问题就已解决。固定联合策略、相同 i.i.d. 问题分布和稳定且匹配的计时模型，是 \(B=0\) 的一个充分情形。若两个 learner 继续任意更新，现有实现没有提供可用的 B 界。

这里的概率模型应明确针对随机问题流及相关运行随机性；不能一面条件化全部未来 benchmark 种子和矩阵，一面仍把这些已知未来问题解释为独立的新随机样本。

定义可计算的剩余净收益下界

\[
\mathcal L_{m,n}(N)
=N L_{m,n}-B_{m,n}(N)-K_{m,n}.
\tag{9}
\]

**建议的部署规则：在 (8) 有依据的范围内，第一次存在候选满足 \(\mathcal L_{m,n}(N)>0\) 时，允许部署该候选。** 若同时有多个候选，可以在已分配误差预算的候选中选择下界最大的一个。这里首先解决的是相对指定 incumbent 的改进，不是全策略空间的最优性。

### 定理 3：自适应部署后的条件期望改进

假设 (5)、(8) 成立，且切换成本不超过 K。则以至少 \(1-\delta\) 的概率，对所有自适应选择的已验证提案及决策时刻，同时有

\[
\mathbb E[\text{未来 N 题净节省}\mid\mathcal G_{m,n}]
\ge\mathcal L_{m,n}(N).
\tag{10}
\]

因此，规则 (9) 错误批准“条件期望净节省非正”的部署的概率，至多为 \(\delta\)。

**证明。** 在 (7) 的同时覆盖事件上，\(\bar g_{m,n}\ge L_{m,n}\)。将其代入 (8)，再减去切换成本上界 K，得到 (10)。由于事件对所有提案和样本数同时成立，事后选择提案与停止时刻不改变该推导。∎

这是与旧 gate 不同的错误事件：这里控制错误批准成本不利的**指定部署协议**。这仍不意味着未来实测总时间在每次运行中都更小。

如果需要实测净节省的高概率保证，需要再控制部署期噪声。例如，若逐题未来条件优势至少为 \(\bar g_{m,n}-d_r\)，其中 d_r 在决策时确定，\(\sum_r d_r\le B\)，且未来中心化成本差满足已知 proxy \(\sigma_{\rm dep}^2\) 的条件 sub-Gaussian 界，则对该次部署的预定 N，

\[
\text{实际净节省}
\ge\mathcal L_{m,n}(N)
-\sigma_{\rm dep}\sqrt{2N\log(1/\eta)}
\tag{11}
\]

的联合失败概率至多为 \(\delta+\eta\)。

**证明。** 条件于部署决策历史，未来中心化差值和的下尾 Hoeffding 界失败概率至多为 \(\eta\)；条件均值和至少为 \(N\bar g-B\)。再与 (7) 合并。∎

若多次部署均要得到 (11)，应为各次部署另分配总和不超过 \(\eta\) 的误差预算；若部署中途任意改变 N 或策略，也需相应的时间一致界或重新验证。

## 7. 回本与部署不是同一个门槛

令 \(I_{m,n}\ge0\) 是从明确的共同起点到决策时，整个新方案相对 incumbent 的累计额外支出的有效上界，包括探索损失、验证、已放弃提案等。它不是只统计 Python update 几毫秒。

如果训练阶段没有观测 incumbent 的反事实成本，就不能把这部分额外支出当作已经精确测得；可使用事先限制的探索预算或保守上界。在配对验证中，第二次求解的成本需要计入 I。

由定理 3 立即得到整个方案的条件期望回本条件

\[
N L_{m,n}>I_{m,n}+K_{m,n}+B_{m,n}(N).
\tag{12}
\]

注意：**I 是 sunk cost。** 已经得到一个候选后，只要 (9) 为正，从此刻起部署它就有可信的边际收益；即使 (12) 不成立，也不应仅因过去投入较大而拒绝今后的节省。式 (12) 用于证明整体方案是否回本，而非普遍替代部署决策。开始训练之前，未来训练投入尚未沉没，当然应纳入最初的投资决策。

### 推论 4：证据成本与剩余预算的兼容条件

考虑一个固定候选，真实优势恒为 \(g>0\)，且 \(B=0\)。提案时有 \(T_0\) 个未处理问题；每个配对验证处理其中一题，额外支出至多 \(\kappa\)，初始额外投入至多 \(I_0\)，切换成本至多 K。

在 (7) 事件上，\(L_{m,n}\ge g-2r_{m,n}\)。因此，只要某个整数 \(n<T_0\) 同时满足

\[
r_{m,n}\le g/4,
\qquad
(T_0-n)g/2>I_0+n\kappa+K,
\tag{13}
\]

最迟在该 n 个验证样本之后可以达到式 (12) 的回本证书。

**证明。** 第一项推出 \(L\ge g/2\)；可部署题数为 \(T_0-n\)，累计额外投入不超过 \(I_0+n\kappa\)。代入 (12)。∎

第一个条件需要足够多证据，第二个条件限制最多能花多少样本获取证据。它们可能没有共同解，即使 \(g>0\)。证据需求随 \(\sigma_m^2/g^2\) 增长（另有对数因子），而证据成本与可用节省均以秒计量。这比指定 100 或 1000 更有解释性，但也说明严谨的有限预算检验不保证总能及时启动。

若训练副本仍持续改善，g 本身也在变化，不能把本推论针对固定候选的样本需求直接称为整个 RL 算法的训练复杂度。

## 8. 如何给联合更新的 B 一个实际数学含义

最简单的可证明范围是：被验证的联合版本在承诺部署期间保持不变，新的学习放在候选副本中。之后新版本再次验证。这样不需要假设更新中的 LSTDQ 已有准确 Q 或准确 sandwich confidence interval，但需要把候选训练的成本记入账本。

若坚持部署后连续更新两个 learner，必须控制更新造成的成本变化。以下给出一个充分条件，展示缺的究竟是什么。

### 引理 5：有限 cycle 数下的联合策略变化界

考虑一个共同问题分布，实际 solver 最多 K_c 个 cycle。设物理 setup+solve+恢复成本位于 \([0,M]\)，相同真实状态与动作使用共同的 solver 转移/成本模型。对参考联合规则 \((\eta,\pi)\) 与更新规则 \((\eta',\pi')\)，假设

\[
\sup_x\operatorname{TV}(\eta'(\cdot\mid x),\eta(\cdot\mid x))\le a,
\quad
\sup_s\operatorname{TV}(\pi'(\cdot\mid s),\pi(\cdot\mid s))\le b.
\]

若两者计算开销的期望差绝对值另有上界 h，则

\[
|J(\eta',\pi')-J(\eta,\pi)|
\le M\min\{1,a+K_c b\}+h.
\tag{14}
\]

**证明。** 对同一个问题作 maximal coupling。setup action 不同的概率至多为 a；在 setup 相同、此前实际轨迹相同的条件下，每个 cycle 的动作分歧概率至多为 b。对至多 K_c 个 cycle 作 union bound，总分歧概率不超过 \(\min(1,a+K_cb)\)。没有分歧时可耦合成相同物理成本，有分歧时成本差绝对值至多为 M。最后加上计算开销变化界 h。∎

若问题分布的 total variation 漂移至多为 q，可在式 (14) 的 min 内再加 q。若 baseline 和 candidate 都漂移，则两边的成本变化界相加，作为未来优势损失 d_r；对 r 求和可构造 B。对历史验证均值的外推，还应计入验证阶段相对参考分布的变化；仅绑定未来阶段不够。

式 (14) 的意义也在于揭示不可用的捷径：

- theta 变化小不保证 greedy action 变化小，尤其在两个动作评分接近时。
- 对确定性策略，某个状态发生动作切换时该状态的 TV 就是 1；不能直接把 theta 的欧氏距离代入 b。
- 只在已访问状态上观察到 action 稳定，不提供整个未来可达状态空间的 sup 界。
- 将新策略混合为 \((1-\alpha)\pi+\alpha\pi'\) 可以保证每状态 TV 至多为 \(\alpha\)，但该界可能很保守，还要满足硬成本界并计入 setup 的变化。

这说明 trust-region 或保守策略更新为何可能相关，却不表示当前实现已具备这些保证。Safe Policy Iteration 也研究如何约束策略改变以得到性能改进；其具体假设和界不能直接套到这里的 \(\gamma=1\)、近似状态和联合 setup 更新上。[Pirotta 等，2013](https://proceedings.mlr.press/v28/pirotta13.html)

### 一个直接联系 LinUCB 的历史成本偏差恒等式

另一个问题是 setup learner 如何使用 RL 启动前后的历史标签。即使假设每个时刻的 setup 成本都可线性表示，表示参数也可能随 downstream solve policy 改变。

令 \(\phi_i\) 为 setup 的 context–action features，观测标签满足
\(y_i=\phi_i^\top\vartheta_i+\epsilon_i\)，其中 \(\vartheta_i\) 表示该时刻下游策略对应的成本模型，\(\epsilon_i\) 为条件均值零的噪声。对 regularization \(\lambda>0\) 的累计 ridge 回归，记

\[
V_t=\lambda I+\sum_{i<t}\phi_i\phi_i^\top,
\qquad
\widehat\vartheta_t=V_t^{-1}\sum_{i<t}\phi_i y_i.
\]

则相对于当前目标 \(\vartheta_t\)，有精确恒等式

\[
\widehat\vartheta_t-\vartheta_t
=V_t^{-1}\left[
 \sum_{i<t}\phi_i\epsilon_i-\lambda\vartheta_t
 +\sum_{i<t}\phi_i\phi_i^\top(\vartheta_i-\vartheta_t)
\right].
\tag{15}
\]

**证明。** 将标签表示代入回归式，再利用
\(V_t\vartheta_t=\lambda\vartheta_t+\sum_{i<t}\phi_i\phi_i^\top\vartheta_t\)
相减即可。∎

前两项是固定目标线性 bandit 分析中的噪声与 regularization；第三项是旧目标与当前目标不同造成的偏差。若已有有效界
\(\beta_t\ge\|\sum_{i<t}\phi_i\epsilon_i\|_{V_t^{-1}}+
\lambda\|\vartheta_t\|_{V_t^{-1}}\)，令

\[
\mathfrak D_t=
\left\|\sum_{i<t}\phi_i\phi_i^\top
 (\vartheta_i-\vartheta_t)\right\|_{V_t^{-1}},
\]

则任意查询特征 \(\phi\) 的预测误差满足

\[
|\phi^\top(\widehat\vartheta_t-\vartheta_t)|
\le\|\phi\|_{V_t^{-1}}(\beta_t+\mathfrak D_t).
\tag{16}
\]

这是加权 Cauchy–Schwarz 的直接结果。标准固定参数置信集所处理的不是任意大小的 \(\mathfrak D_t\)。[Abbasi-Yadkori、Pál 和 Szepesvári，2011](https://papers.nips.cc/paper_files/paper/2011/hash/e1d5be1c7f2f456670de3d53c7b54f4a-Abstract.html)

这个恒等式说明，启动时不仅要考虑 RL 是否学得动，还要考虑 setup 的旧成本标签是否仍对当前目标有效。failure history 不约束 \(\mathfrak D_t\)，数值上准确地求解回归方程也不消除它。它可能在特定数据上抵消或较小，因此不能据此声称已量化 4D 的实际偏差。

当前实现的探索系数本来就未按标准高概率置信半径校准；式 (16) 更不能反过来为该系数提供保证。分开维护不同下游策略下的成本模型、对历史作有依据的重加权、或在更新协议中控制目标变化，都属于下一步可研究的修改。单纯重置所有统计量会丢失信息，并没有由上述恒等式得到自动改进保证。

## 9. 开始训练仍需要什么

上述判据解决的是“已获得某个候选后，何时部署”，没有绕过训练数据的来源问题。令 action basis 为 \(\zeta(w)\in\mathbb R^{d_w}\)（旧笔记的 \(b(w)\)），则默认 action 下 \(\zeta(w_0)\otimes\varphi(s)\) 的跨度至多为 \(d_s\)，一般无法识别 \(d_wd_s\) 的完整 action-value 参数。Ridge 可逆性不能弥补未尝试动作的信息缺失。

因此，若要建立完整方法，可以采用如下协议，而不再把一次 failure crossing 当作永久联合部署：

1. 用当前 incumbent 处理问题；明确一个获取候选数据的探索预算和恢复规则。
2. 在允许的探索问题上训练候选；旧 reliability evidence 最多作为进入这个阶段的运行条件。
3. 保存完整联合候选，使用新的配对问题按式 (6) 持续验证。
4. 依据式 (9) 决定部署，依据式 (12) 分别报告整个方案是否已有回本证书。
5. 后续实质性更新形成新提案，或者提供式 (8) 所需的更新/分布变化界。

从严格决策论看，第 1 步何时购买信息仍是式 (2) 扩展后的 value-of-information 问题。没有先验模型、已有跨动作数据或可证明的探索学习界，就不存在一个仅靠默认失败轨迹得到、同时保证成本最优的训练开始公式。探索预算应是明确的资源约束，不应伪装成已经证明最优的常数。

Conservative bandit 文献将探索与基线性能约束同时建模，但其已知/可置信估计的基线与回报模型条件必须具体检查。这里引用它作为问题设计的参照，不声称 CLUCB 的 regret 定理已经适用于本项目。[Kazerouni 等，2017](https://papers.nips.cc/paper_files/paper/2017/hash/bdc4626aa1d1df8e14d80d345b2a442d-Abstract.html)

## 10. 对当前实验和论文主线的具体影响

1. **保留旧结果的正确解释。** 4D dynamic 提早阶段的实际节省与后续联合组合较慢可以同时成立。不能据此把启动阈值改得更保守，就宣称已经解决长期路径问题。
2. **明确 cost comparator。** 首次比较 bandit+default 与候选时，应说明 setup selector 是相同、分别冻结，还是继续更新的两个协议。以后每个定理与图表使用同一口径。
3. **已有 25+25 个冻结样本是机制证据。** 尤其最终 checkpoint 对训练过的问题的回看，不是上述新候选的前瞻验证数据。不能用它们事后调 \(\delta\)、\(\sigma\) 或 B，再报告具有定理 3 的 nominal coverage。
4. **不再要求“dynamic 在全部 case 上超过 fixed1000”。** 可主张的目标是有条件的成本改进、有限预算收益和跨重复实验的统计表现；理想 optimal stopping 的期望最优性不能转移给未经证明的实现。
5. **部署检验不依赖 v3 的 uncertainty 已校准。** LSTDQ 可以作为候选生成器；检验直接观察完整策略成本。其有效性与候选训练是否恰好满足线性 Q realizability 分开。相应地，这也不证明 LSTDQ 一定学出优于 best fixed 的策略。
6. **暂不扩大为新实验矩阵。** 若下一步实现成本部署规则，真正必需的是候选确定后的新验证证据及完整成本账本。若要识别“开始训练的时刻”本身，则需要共同前史处分叉的立即启动/延后启动比较；这服务于不同主张，不能互相替代。

从论文范围看，这份分析最有价值的部分是式 (1) 的联合路径问题、训练/部署/回本的区分，以及式 (8) 中明确的外推条件。式 (6) 的统计工具与式 (10) 的代入证明本身不是新的通用理论贡献。若把它们写入 主线，应突出它们如何约束和解释实际的 AMG 联合自适应算法，而不通过增加定理数量来代替算法层面的论证。

当前完成的是上述反例、分解、confidence sequence、部署/回本保证、策略变化界与历史目标偏差恒等式的证明。尚未完成、也没有在本文件中假定已完成的工作是：实际 wall-clock 噪声界的校准、现有连续联合更新的可用 B 界、训练开始的最优性、以及新协议的前瞻实证验证。
