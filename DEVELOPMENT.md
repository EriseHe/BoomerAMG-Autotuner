# Development

This branch, `online-bandit-rl`, retains the Module 04, 05, and 06 names,
development source, and experiment history. Full datasets are in
`data/official/`; other experiments and their controls are in the local
`data/archive/`. Large files are excluded from Git.

The reviewer release is on `main`, with the three studies named Module 1,
Module 2, and Module 3. Its saved measurements, figures, and table values are
checked against these development records. Release tooling is under `tools/`;
verification receipts are in `data/archive/organization/reviewer_release/`.
